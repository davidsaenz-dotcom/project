Newtonian Gravitation Calculator!

How to Use:

First, select what you want to calculate for using the provided radio buttons. The inputs the program asks for will then change according to what you selected. After you input the values requested, you may click on the calculate button to calculate the value that you chose. Below the Calculate button, the program will display a list with your inputted values, alongside the calculated value.
